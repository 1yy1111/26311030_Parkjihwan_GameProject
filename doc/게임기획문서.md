# 게임 기획서

- **작성자:** 박지환
- **게임 제목:** Crash Out
- **게임 장르:** 2D 자동차 회피 아케이드
- **개발 환경:** C++, Visual Studio 2022, glc2d

---

## 1. 게임 개요

- 플레이어 자동차와 상대 자동차가 2차선 순환 트랙을 서로 반대 방향으로 주행하는 게임이다. 플레이어는 마우스를 클릭하여 안쪽 차선과 바깥쪽 차선 사이를 이동하며 상대 자동차와의 충돌을 피한다.

- 자동차는 자동으로 움직이며, 플레이어가 직접 속도나 진행 방향을 조종하지 않는다. 충돌하지 않고 트랙을 한 바퀴 돌 때마다 점수를 얻고, 충돌하면 게임이 종료된다.

---

## 2. 게임 목적

상대 자동차와 충돌하지 않도록 차선을 바꾸며 최대한 많은 바퀴를 완주하는 것이다.

---

## 3. 조작 방법

| 입력 | 기능 |
|---|---|
| Enter | 시작 화면에서 게임 시작 |
| 마우스 왼쪽 클릭 | 플레이 중 내 자동차의 차선 변경 |
| Enter | 결과 화면에서 새 게임 시작 |
| Esc | 프로그램 종료 |

- 차선 변경은 화면의 어느 위치를 클릭해도 적용된다.
- 마우스 버튼을 누른 채 유지해도 차선이 반복해서 바뀌지 않는다. 새로 클릭할 때마다 한 번 바뀐다.
- 시작 화면과 결과 화면에서는 클릭에 의한 차선 변경을 처리하지 않는다.

---

## 4. 게임 시작 조건

- 프로그램을 실행하면 게임 제목과 시작 안내가 표시된다.
- Enter 키를 누르면 게임 진행 화면으로 이동한다.
- 시작 시 점수와 누적 주행량은 0으로 초기화한다.
- 두 자동차 모두 바깥쪽 차선에서 시작한다.
- 내 자동차는 시계 방향, 상대 자동차는 반시계 방향으로 주행한다.
- 상대 자동차의 차선 변경 판단은 출발 후 첫 번째 변경 구간에 진입할 때부터 적용한다.
- 두 자동차는 아래쪽 직선 구간의 출발선을 사이에 두고, 서로 겹치지 않도록 간격을 두어 배치한다. 내 자동차는 출발선 왼쪽, 상대 자동차는 오른쪽에서 시작한다
---

## 5. 기본 게임 규칙

### 트랙과 자동 주행

- 화면 중앙에 안쪽·바깥쪽의 두 차선이 있는 2차선 순환 트랙을 배치한다.
- 트랙과 카메라는 고정한다.
- 정해진 트랙을 벗어나지 않는다.
- 자동차 이미지는 진행 방향을 향하도록 표시한다.
- 내 자동차는 한 바퀴를 완주할 때마다 주행 속도가 일정량 증가한다.

### 내 자동차의 차선 변경

- 왼쪽 클릭을 한 번 하면 현재 차선에서 반대 차선으로 이동한다.
- 차선을 변경할 때 트랙을 따라 진행한 위치를 유지한 채, 반대 차선의 대응 위치로 즉시 이동한다.
- 차선 변경으로 바뀐 위치도 충돌 판정 대상이다.

### 상대 자동차의 차선 변경

- 상대 자동차의 진행 방향을 기준으로, 좌·우 커브가 끝나고 직선으로 이어지기 전 구간을 차선 변경 구간으로 정한다.
- 변경 구간에 진입하면 현재 차선을 유지할지 반대 차선으로 변경할지 무작위로 결정한다.
- 변경하기로 결정하면 앞으로 주행하면서 반대 차선으로 부드럽게 이동한다.
- 차선 변경은 직선 구간에 진입하기 전까지 완료한다.
- 변경 구간에 한 번 진입할 때 유지·변경 결정은 한 번만 처리한다.
- 차선을 변경하는 도중에도 충돌 판정을 적용한다.


### 충돌과 종료

- 자동차마다 작은 충돌 영역을 두고, 두 영역이 겹치면 충돌로 처리한다.
- 충돌 영역은 자동차 그림에 맞춰 정하며, 나란한 차선에서 정상 주행 중인 자동차끼리 충돌하지 않도록 조정한다.
- 충돌하면 두 자동차의 이동을 멈추고 결과 화면으로 전환한다.
- 목숨은 1개이며, 피격 후 무적이나 부활 기능은 사용하지 않는다.
---

## 6. 점수 규칙

| 항목 | 규칙 |
|---|---|
| 시작 점수 | 0점 |
| 점수 획득 | 내 자동차가 한 바퀴를 완주할 때마다 1점 |
| 차선 변경 | 점수 변화 없음 |
| 실패 조건 | 상대 자동차와 충돌 |
| 게임 결과 | 충돌하기 전까지 완주한 바퀴 수 표시 |

- 차선 변경 횟수나 상대 자동차의 주행에는 점수를 주지 않는다.
- 차선 변경 시 누적 주행량은 초기화하지 않는다.
- 내 자동차가 트랙 전체를 주행하여 출발선을 다시 통과하면 한 바퀴를 완주한 것으로 판단한다.
- 출발 위치에 처음 배치된 순간에는 점수를 주지 않는다.
- 충돌과 한 바퀴 완주가 같은 업데이트에서 발생하면 충돌을 먼저 처리하고, 해당 업데이트의 완주 점수는 추가하지 않는다.
- 기본 게임에는 목표 점수에 따른 클리어와 제한 시간을 두지 않는다. 충돌할 때까지 기록을 높이는 방식이다.

---

## 7. 게임 종료와 재시작

- 자동차가 충돌하면 게임오버 문구와 최종 점수를 표시한다.
- 결과 화면에서 Enter 키를 누르면 점수, 자동차 위치·방향·차선, 누적 주행량과 상대 차선 변경 판정 상태를 모두 초기화한다.
- 초기화 후 바로 새 게임을 시작한다.
- Esc 키 또는 창 닫기로 프로그램을 종료한다.

---

## 8. 주요 게임 객체

| 객체 | 역할과 행동 |
|---|---|
| 내 자동차 | 트랙을 시계 방향으로 주행하고 클릭에 따라 차선을 변경한다. |
| 상대 자동차 | 반시계 방향으로 주행하고, 커브 끝부분에서 무작위로 차선 유지·변경을 결정한다. |
| 트랙 | 두 자동차의 이동 경로와 두 차선의 위치를 나타낸다. |
| 점수 표시 | 내 자동차의 완주 바퀴 수를 보여 준다. |
| 화면 관리 | 시작, 플레이, 결과 화면에 맞는 입력과 출력을 처리한다. |

별도의 장애물과 아이템은 사용하지 않는다. 위 목록은 역할을 정리한 것이며, 각 항목을 반드시 별도 클래스로 만들지는 않는다.

## 9. 게임 화면 구성

### 시작 화면

- 중앙 위쪽: 게임 제목.
- 아래쪽: “Enter 키를 눌러 시작” 안내.

### 게임 진행 화면

- 화면 중앙: 직선과 커브로 구성된 2차선 순환 트랙
- 트랙 위: 서로 다른 색으로 구분되는 내 자동차와 상대 자동차.
- 트랙 안쪽의 빈 공간: 현재 점수.

### 결과 화면

- 주행을 멈춘 게임 화면 위에 결과를 표시한다.
- 중앙: “GAME OVER” 문구.
- 중앙 아래쪽: 최종 점수와 완주 바퀴 수.
- 아래쪽: “Enter: 다시 시작 / Esc: 종료” 안내.

---

## 10. 게임 진행 흐름

1. 프로그램 실행 후 시작 화면을 표시한다.
2. Enter 입력을 받으면 게임 데이터를 초기화한다.
3. 두 자동차가 반대 방향으로 자동 주행한다.
4. 플레이어의 클릭과 상대 자동차의 규칙에 따라 차선을 변경한다.
5. 충돌 여부를 확인한다.
6. 충돌하지 않았다면 완주 여부를 확인하고 점수를 갱신한다.
7. 충돌할 때까지 주행, 입력, 판정과 점수 갱신을 반복한다.
8. 충돌하면 결과 화면에 최종 점수를 표시한다.
9. Enter 입력 시 새 게임을 시작하거나 Esc 입력 시 종료한다.

## 12. 제작 범위


- 직선과 커브로 구성된 트랙 1개
- 안쪽·바깥쪽 차선 2개.
- 내 자동차와 상대 자동차 각 1대.
- 두 자동차의 자동 주행과 진행 방향 표시.
- 클릭에 따른 내 자동차의 차선 변경.
- 커브 끝부분에서 무작위로 결정하는 상대 자동차의 부드러운 차선 변경.
- 자동차 사이의 충돌 판정.
- 완주 바퀴 수에 따른 점수 계산.
- 시작 화면, 플레이 화면, 결과 화면과 재시작.
